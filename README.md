# A little note for you

A small, mobile-friendly apology website with a night sky, drifting fireflies, an interactive letter and no-pressure response buttons. It uses plain HTML, CSS and JavaScript; there is no build step or dependency to install.

## Personalize it

1. Open `script.js` in any text editor.
2. Replace `[Her name]` and `[Your name]` in the `names` object near the top.
3. Open `index.html` and replace `[what I did or said]` with a specific, honest description. The highlighted phrase can also be edited right on the page before you share it.
4. Read the whole note and adjust any wording so it sounds like you.

## Run it

Double-click `index.html` to open it in a browser. For local hosting, place the folder on any static web host, such as GitHub Pages, Netlify, or Cloudflare Pages. No server-side code is required.

## Share it

Upload the three site files (`index.html`, `style.css`, and `script.js`) to a static host and share its page link. Keep `README.md` for your own reference. The Google Fonts connection is optional; the page falls back to system fonts if offline.
